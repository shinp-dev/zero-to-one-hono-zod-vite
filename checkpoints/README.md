# 授業チェックポイント

各回の **開始時 (`start/`)** と **終了時 (`end/`)** の実プロジェクトです。学生が途中でコードを壊した場合や、欠席後に途中回から再開する場合の復旧用に使います。

## 使い方

使いたいフォルダを別の作業場所へコピーして、そのフォルダで実行します。

```bash
npm install
npm run dev
```

第6回以降のチェックポイントは、復旧しやすいよう `predev` でローカルD1へ `schema.sql` を自動適用します。

## 対応表

| 回 | start | end |
|---|---|---|
| 第1回 | 公式構成を教材用に最小化した初期状態 | 環境・TypeScript確認済み |
| 第2回 | 第1回 end | GET `/api/messages` 完成 |
| 第3回 | 第2回 end | POST + Zod 完成 |
| 第4回 | 第3回 end | React一覧・投稿UI完成 |
| 第5回 | 第4回 end | Hono RPCで型安全化 |
| 第6回 | 第5回 end | D1永続化完成 |
| 第7回 | 第6回 end | 公開・デバッグ確認後の最終状態 |

## 原則

- `session-N/end` と `session-(N+1)/start` は同じ実装状態です。
- 第1回は理解と環境確認が中心なので、start/endの実装差はほぼありません。
- 第7回はデプロイ・検証が中心なので、第6回endから大きなコード変更はありません。
- チェックポイントは教材の復旧用です。実際の授業では、各Stepを自分で変更して動作確認してください。
- 第6〜7回の `database_id` はローカル復旧用ダミーです。本番デプロイ時は自分のD1 IDへ置き換えてください。

## 更新ルール

教材本文を変更して各回の完成状態が変わった場合は、対応する `end/` と次回の `start/` を同時に更新します。
